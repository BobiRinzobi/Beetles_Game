# Игровое приложение «Жуки»

Аркадная мобильная игра на платформе Android, проверяющая скорость реакции и точность игрока.

### Описание и игровой процесс
Главная цель игры - набрать как можно больше очков, уничтожая хаотично передвигающихся по экрану насекомых.

* **Уничтожение целей:** При нажатии на картинку насекомого оно исчезает, а на счет игрока начисляются очки.
* **Штраф за промах:** Каждое нажатие мимо цели (по пустому экрану) влечет за собой штрафные очки или потерю жизней.
* **Разнообразие:** На игровом поле одновременно могут появляться разные виды насекомых с различной скоростью и траекторией движения.
